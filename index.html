Projects

Chess

C++ / SDL2

A complete two-player chess game with an optional built-in AI, rendered with SDL2. Features full rules (castling, en passant, promotion, threefold repetition, 50-move rule), SAN move list, legal-move hints, capture tray with material advantage, and Stockfish support.

Watch mode lets two engines battle it out while every move is graded lichess-style (miss, good, brilliant...).

SATISFY

C++17

A satisfying terminal toybox in a single C++ file — no dependencies beyond a POSIX terminal and g++. Nine little worlds with true color and mouse support: falling sand with 15 reacting materials, Game of Life, water-ripple simulation, particles, fireworks, boids, plasma, glyph rain, and a zen mode.

Password Generator

Python

A tiny utility that generates strong random passwords using Python's secrets module, ensuring a balanced mix of lowercase, uppercase, digits, and symbols.
