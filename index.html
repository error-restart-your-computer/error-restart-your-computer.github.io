Projects

Chess C++ / SDL2

A complete two-player chess game with an optional built-in AI, rendered with SDL2. Full rules — castling, en passant, promotion, threefold repetition, the 50-move rule — plus a SAN move list, legal-move hints, a capture tray with material advantage, and Stockfish support when it's available.

Watch mode lets two engines battle it out while every move is graded lichess-style (miss, good, brilliant…).

SATISFY C++17

A satisfying terminal toybox in a single C++ file — no dependencies beyond a POSIX terminal and g++. Nine little worlds with true colour and mouse support: falling sand with 15 reacting materials, Game of Life, a real water-ripple simulation, particles, fireworks, boids, plasma, glyph rain, and a zen mode.

Password Generator Python

A tiny script that generates strong random passwords with Python's secrets module — guaranteeing at least one lowercase letter, uppercase letter, digit, and symbol.
